# 03 UI/UX 개선 (2026-10-09)

사용자 요청: "uxui전문에이전트는 전체 프로그램 uxui분석하고 사용자편의성 관점 개선사항 도출해줘" → "전부수정해봐"
검토자: .claude/agents/ui-ux-reviewer (화면 사진 기반 검토, 제안만 함). 아래 제안을 모두 반영함.

## 공통
- 하단 출처 글: 접을 수 있게 바꿈("출처·안내"). 컴퓨터 화면에서는 펼친 채로 시작하고, 폰에서는 접힌 채로 시작. "만든 사람"은 항상 보임. 글자색은 더 밝게.
- 상태 글(#status)이 출처 글과 겹치던 문제: 위치를 올리고 배경을 깔았으며, 내용이 없으면 숨김.
- 폰: 체크박스·배속 버튼의 누르는 영역을 키우고, 작은 글씨를 조금 키움.
- 이름표가 정보창 위로 올라오던 문제: 이름표 층(#labels)을 정보창 아래로 내림.
- "위성 추적으로" 버튼 색을 더 진한 주황(#c2410c)으로 바꿔 글자가 잘 보이게 함.

## 태양계 (index.html, src/main.js)
- 오타 수정: 입축 → 압축.
- 천체를 고르면 화면 위에 정보창(#bodyCard)이 뜸. 컴퓨터는 오른쪽 위, 폰은 아래쪽. ✕로 닫을 수 있음.
- 처음 들어오면 사용법 안내(#firstTip)가 잠깐 보였다가 사라짐.
- 화면 정리: 혜성·소행성 이름표는 고른 것, 가까운 것, 성간천체만 보임. 제임스웹 이름표는 가까이 갔거나 골랐을 때만 보임. 혜성·소행성 궤도선은 더 흐리게.

## 국내 위성 (satellites.html, src/sat/)
- 정보창의 닫기(✕) 버튼을 키움(폰은 더 크게).
- 배속 아래 "지금으로·일시정지" 버튼은 한 줄에 크게 두고, 설명 글은 그 아래로 옮김.
- 지구 시점:
  - 밤에 땅이 크림색으로 보이던 문제 수정(지구 밤 불빛이 땅을 뚫고 보였음 → 지구 시점에서는 지구 본체를 숨김).
  - "이 시간으로"를 누르면 통과 목록이 접히고, 위성이 떠오를 쪽 지평선을 보며 기다렸다가, 위성이 뜨면 화면이 그 위성을 따라감. 직접 드래그하면 따라가기를 멈춤. 하늘 목록에서 위성을 눌러도 따라감.
  - 막 끝난 통과는 5분 동안 회색 "지남"으로 남겨, 목록 줄이 갑자기 밀리지 않게 함.
  - 통과 목록의 버튼을 키움.

## 우주망원경 (telescope.html, src/telescope/main.js)
- 패널 순서: 설계 값 → 성능 요약 → 표시 → "더 알아보기 (고급 계산)".
- 고급 계산 칸(별빛 번짐·관측 시간 계산·차양막 비교)은 접어 두고, 펼쳤을 때만 계산함(느려지지 않게). 각 칸에 쉬운 설명과 용어 풀이를 붙임.
- 관측 시간 계산 맨 위에 "판정: 가능 / 시간이 더 필요 / 불가능"을 한 줄로 보여 줌.
- 차양막 비교는 폭이 좁은 표 대신 카드 모양으로 바꿈.
- 폰: 위쪽 버튼 줄이 화면을 덜 차지하게 바꿈(높이 395px → 187px). 망원경 화면이 아닐 때는 아래 진행 막대를 숨김.
- 이름표 위치 정리(태양전지판 이름표, 지구 시점의 은하 이름표).
- 폰에서 "전개 -46%"처럼 음수가 나오던 문제 수정(한 프레임의 시간 간격을 0~0.1초로 제한).

## 확인
- 헤드리스 크롬으로 컴퓨터 화면(1280×800)과 폰 화면(390×844)에서 세 페이지를 열어 봄. 오류 없음.
  - 태양계: 화성을 고르면 정보창이 뜸. 사용법 안내가 보임. 상태 글과 출처 글이 겹치지 않음.
  - 위성: 지구 시점에서 "이 시간으로"를 누르면 목록이 접히고 위성이 화면 가운데로 따라옴.
- `node scripts/test-telescope-calc.mjs`, `node scripts/test-telescope-smoke.mjs` 통과.
