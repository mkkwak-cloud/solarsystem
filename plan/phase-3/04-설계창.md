# 04 이름 변경·설계창 기본 표시 (2026-10-09)

사용자 요청: "우주망원경설계시뮬레이터로 이름 변경하고 설계가기본이니깐 하단에 설계바 디폴트로 뜨게하고 폰에서볼때 망원경 시뮬이 안보이니 지금보다 절반축소 스크롤로 파라미터 변경할수있게"

## 한 일
- 이름: "우주망원경 설계 시뮬레이터" (telescope.html 제목·머리글, 태양계·위성 페이지 이동 버튼, 태양계 제임스웹 정보창, README).
- 설계창(파라미터)이 처음부터 열려 있음. 폰에서도 열린 채로 시작(전에는 닫힌 채 시작).
- 폰: 설계창을 화면 아래에 두고 높이를 전의 절반(화면 46% → 23%)으로 줄임. 창 안에서 스크롤해 값을 바꿈.
- 폰에서 3D 화면을 눌러도 설계창은 닫히지 않음(설명 글만 닫힘). "⚙ 설계 닫기/열기" 버튼으로 접고 펼침.
- 망원경이 가리지 않게: 위쪽 글과 설계창 사이 빈 곳의 가운데로 화면 중심을 옮기고, 빈 곳이 좁으면 조금 멀리서 봄. 컴퓨터에서는 오른쪽 설계창만큼 중심을 왼쪽으로 옮김.
- 시험 스크립트(test-telescope-smoke.mjs)의 가짜 화면 요소에 새로 쓰는 기능을 추가.

## 확인
- 헤드리스 크롬: 폰(390×844)에서 망원경 전체가 설계창 위 빈 곳에 보이고, 설계창 안 스크롤 동작. 컴퓨터(1280×800) 정상. 오류 없음. smoke 시험 통과.

## 남은 결정(사용자 답 대기)
- 망원경 형태를 ① 접어서 한 번에 쏘기 ② 우주 조립·제작 ③ 여러 대 나눠 띄우기 로 다시 묶을지.
- 거울 조절 기능: 제임스웹 거울 맞추기 재현 / 직접 조절 / 초점 조절 중 무엇을 만들지.
