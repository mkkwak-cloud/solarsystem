# 02-구현계획 (PRD v0.4 기준, 승인 대기)

## 폴더 구조
```
solarsystem/
  index.html            화면 뼈대
  PRD.md  HANDOFF.md  README.md(M7)
  src/
    main.js             시작점, 반복 루프
    data/               읽어서 쓰는 코드 (JSON 로더)
    sim/                clock.js(시계) / planets.js(행성 위치) / kepler.js(혜성·소행성 계산) / scale.js(거리 변환)
    scene/              만들어서 화면에 올리는 것: sun, planets, orbits, labels, moons, comets, asteroids, belt, voyager
    ui/                 panel.js(좌측 패널), cards.js(정보 카드), loader.js(로딩 바)
  data/                 comets.json asteroids.json moons.json voyager.json (사전 조회한 값)
  textures/ (+fictional/)  models/  raw/(커밋 제외)
  scripts/              다운로드·변환·생성, fetch-*.js
```
- 라이브러리(three.js, astronomy-engine)는 `vendor/` 에 내려받아 넣는다 → 인터넷 없이 실행 가능.
- 실행: `py -m http.server` (파이썬 내장 서버).

## 단계 (PRD 8장 그대로)
| 단계 | 할 일 | 끝났다는 확인 |
|---|---|---|
| M0 | 텍스처 받기 → 2K 변환 → 가상 텍스처 → CREDITS.md | 실패 목록 + 천체별 표 |
| M1 | 3D 씬, 행성 8개, 궤도선, 시간·날짜, 좌측 패널, 카드 | 브라우저에서 실행, 스크린샷 |
| M2 | 거리 스케일 3종, 크기 슬라이더, 표시 옵션, 궤적 | 3모드 전환 확인 |
| M3 | 위성 25개, 줌 연동, 포커스, 위성 텍스처 | 접근 시 나타남 |
| M4 | 혜성 20 + 3I/ATLAS, 꼬리 | 핼리 2061년경·네오와이즈 2020년 위치 |
| M5 | 소행성 9개 + 장식용 소행성대 | 3모드에서 화성~목성 사이 유지 |

| M7 | 자전, 성능, 출처 표기, 수락 기준 13개 점검, README | 통과/미통과 표 |

## 지켜야 할 규칙
- 값은 출처 있는 것만. 모르면 "모른다"고 보고. 주소는 추측하지 않음.
- 각 단계 끝에 실제로 실행해서 확인한 것만 보고.
- 단계마다 끝나면 HANDOFF.md 갱신. 커밋은 "cmt" 하실 때만.

## M0 에서 미리 알려드릴 점
- USGS 큰 지도 합계가 약 1.2GB(어림값: 베스타 341 + 명왕성 296 + 트리톤 287 등). 디스크 여유와 시간이 필요합니다.
- USGS 는 자동 다운로드를 막을 수 있습니다(PRD에 403 경험 기록). 막히면 파일명·주소 목록을 드리니 브라우저로 받아 `raw/` 에 넣어 주셔야 합니다.
- 이오~칼리스토, 레아 주소는 아직 모름 → 페이지에서 확인해 보고, 안 되면 단색 구체로 둠.
