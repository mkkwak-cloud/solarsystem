# 04-검증 (M7, 2026-10-06)

시험 방법: 로컬 서버 + 자동 브라우저(Edge, puppeteer-core, 프로젝트 밖 임시 폴더)로 실행해 화면·수치를 확인. 성능은 실제 그래픽카드(Intel Iris Xe)로 측정.

## 2. 성능 (실제 그래픽카드: Intel Iris Xe, 프레임 제한 해제)

| 상황 | 초당 프레임 |
|---|---|
| 기본 화면 (배속 10x) | 125 ~ 215 |
| 보이저 1·2호까지 전부 켠 상태 | 145 ~ 186 |
| 배속 32000x | 141 ~ 157 |
| 목성에 접근(위성·궤도·이름표 표시) | 120 ~ 158 |

목표 60fps 대비 충분(같은 측정을 두 번 했을 때 값 차이가 있어 범위로 적음). 그리기 호출 102개, 삼각형 약 1만 개, 텍스처 26장. 이 컴퓨터보다 약한 그래픽(구형 노트북 등)에서는 측정하지 못함.
참고: 소프트웨어 그래픽(그래픽카드 없음) 환경에서는 약 5~20fps.

## 3. 로딩

- 시작할 때 불러오는 텍스처 합계 14.95 MB (파일 40개, 행성+별+고리+위성+소행성). 목표 20 MB 이하 충족.
- 불러오는 순서: 태양·지구부터 요청하고 나머지 행성, 별 하늘, 고리 순. 위성·소행성 텍스처는 행성 다음에 조용히(동시 3개) 불러옴. 로딩 바는 행성·별·고리 기준으로 진행.

## 4. 자전 (M7 추가)

IAU 자전 요소(북극 방향, 위상, 자전 속도)를 `src/data/rotation.js`에 적고 NASA 행성 자료표로 대조.

| 행성 | 자전 주기 차이 | 기울기(우리 값 / NASA) |
|---|---|---|
| 수성 | 0.01% | 0.04° / 0.034° |
| 금성 | 0% | 2.64° / 177.4° (IAU 북극 정의로 보각 관계: 180−177.4=2.6°) |
| 지구 | 0.14% | 23.44° / 23.4° |
| 화성 | 0.09% | 25.19° / 25.2° (극 방향 값을 JPL 위성표 값으로 바로잡음) |
| 목성 | 0.25% | 3.12° / 3.1° |
| 토성 | 0.41% | 26.74° / 26.7° |
| 천왕성 | 0.23% | 82.23° / 97.8° (보각 관계: 180−97.8=82.2°) |
| 해왕성 | 0.83% | 28.32° / 28.3° (J2000 시점 값으로 바로잡음) |

- 지구 위상 시험: 6월 21일 12:00 UTC 태양 아래 경도 +0.6°, 18:00 UTC −89.4°, 00:00 UTC −179.4°, 태양 아래 위도 하지 +23.4° / 동지 −23.4° (모두 기대값과 일치).
- 토성 고리면은 토성 적도면(자전축에 수직)에 맞춤. 2026년은 고리가 옆으로 서는 시기라 얇게 보이는 것이 맞고, 카메라를 돌리거나 날짜를 2017년으로 바꾸면 열린 고리가 보임.
- 배속이 빠르면(10x = 지구가 초당 10바퀴) 자전이 빙글빙글 보임. "행성 자전" 체크박스로 끌 수 있음.

## 5. 이번에 바로잡은 것

- 화성·해왕성 극 방향 (기억값 → NASA 기울기와 JPL 표로 대조해 수정).
