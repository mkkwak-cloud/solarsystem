# 02-구현 (국내 위성 추적 페이지)

## 만든 것
- satellites.html + satellites.css + src/sat/{main,info,danuri}.js (태양계 페이지와 별개, 서로 링크).
- vendor/satellite.min.js (satellite.js 5.0.0, MIT) — 위성 궤도 계산(SGP4).
- scripts/fetch-korean-sats.js → data/kr-sats.json : CelesTrak SATCAT 에서 소유국 SKOR(+누리호 5차 발사일 건) 중 소멸 안 된 것 66개와 TLE.
- scripts/fetch-danuri.js → data/danuri.json : JPL Horizons -155(다누리), 달 중심, 15분 간격, 2026-09-01~2027-05-06(Horizons 끝날). 3차 에르미트 보간. TDB→UTC 69.184초 보정.
- src/sat/info.js : 위성별 한글 이름·소유기관·용도(공개 자료 정리, 모르는 칸은 "확인 중"), 누리호 5차 대기 목록(PENDING).

## 결정
- 거리 압축 없이 실제 비율 (지구 반지름=1, 달 60.3). 확대/축소로 충분.
- 달·태양 방향은 J2000→날짜 적도 좌표로 돌려 TLE 좌표(TEME)와 맞춤.
- 누리호 5차(2026-10-07, 성공, 큐브 PERSAT-02 사출 실패)는 CelesTrak 번호 미등록 → 목록에만 "데이터 대기 중". 번호가 올라오면 fetch-korean-sats.js 를 다시 돌리면 지도에 나옴(NEONSAT-2~6 은 이름으로 자동 연결).
- CelesTrak 은 CORS 허용 → 페이지의 "최신 궤도 정보 받아오기" 버튼이 브라우저에서 바로 갱신(저장본은 그대로).

## 한계·알아둘 점
- 이름 미확정 위성: 누리호 4차 OBJECT B/C/G(세종4호·ETRI Sat·PERSAT 중 하나), 3차 OBJECT E/F/G. info.js 에 그렇게 표기.
- 용도 칸 중 "확인 중" 다수(PVSAT 외 2차 큐브, 경기위성·부산샛 등). 425 사업 위성은 "알려짐" 수준만.
- 궤도 정보(TLE)는 날짜가 멀어지면 오차 증가(14일 넘으면 화면에 경고).
- 다누리 자료는 2027-05-06까지.
