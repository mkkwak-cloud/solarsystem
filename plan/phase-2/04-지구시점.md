# 04-지구시점 (국내 위성 페이지)

- 2026-10-09 사용자: "국내위성도 뷰를 지구시점 뷰도 추가 디폴트위치는 서울"

## 만든 것
- src/sat/ground.js (+ main.js 연결, satellites.html 버튼·위치 선택, satellites.css).
- "보기"의 **지구 시점 (하늘 올려다보기)** 버튼: 관측 지점 지표(높이 약 1.3 km)에 카메라를 두고 지구 자전을 따라 같이 돈다. 위성은 실제 계산 위치 그대로라 하늘을 지나가고, 지평선 아래는 지구에 가려진다.
- 조작: 드래그 = 둘러보기(방위·고도), 휠 = 시야 15~100°. 지평선에 동서남북·천정 표시. 해 고도에 따라 낮 하늘(파란 막) 표시.
- "하늘의 국내 위성" 목록: 지금 지평선 위 위성을 고도 순으로(방위·고도, 햇빛/그림자, 어두운 하늘 + 햇빛이면 "맨눈 가능"). 누르면 선택 + 그쪽 하늘을 바라봄. 제목을 누르면 접힘(폰에서 하늘을 가리지 않게).
- 관측 위치: 서울(기본)·대전(한국천문연구원)·부산·제주·나로우주센터·내 위치(GPS, 브라우저 권한 필요). 주소 satellites.html?view=ground 로 바로 지구 시점 시작.
- 지구 시점에서는 구름·대기 막·지표 지명표·확대 3D 모형을 숨기고, 목록의 "따라가기"는 그 위성 쪽 하늘을 바라보는 것으로 바뀜.

## 결정
- 방위·고도는 satellite.js(ecfToLookAngles)로 계산하고, 화면 방향은 지구 구체의 국소좌표(main.js 의 addSite 와 같은 규칙)에서 동·북·위 축을 만들어 맞춤.
- 위성이 햇빛을 받는지는 지구 원통 그림자로 판단(반그림자 무시).

## 시험 (헤드리스 크롬)
- 2026-10-09 12:30 UTC(서울 21:30) 서울: 지평선 위 9개, 천리안 2A·2B 남 178°·고도 46°(동경 128° 정지궤도 기대값과 일치). satellite.js 방위·고도로 조준했을 때 화면 정중앙과 실제 위성 방향 차이 0.03°.
- 낮(03:00 UTC)은 파란 하늘·"햇빛" 표시, 끄면 원래 지구 전체 보기·지명표 복귀, 폰 폭(400px) 확인, 페이지 오류 0.
