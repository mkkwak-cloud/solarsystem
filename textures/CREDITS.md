# 텍스처 출처 (2026-10-06 M0 기준)

"이용 조건" 칸에서 "확인함"은 해당 페이지에서 읽은 것(2026-10-06, 페이지 내용을 요약 도구로 읽음), "확인 필요"는 아직 확인하지 못한 것입니다.
USGS 지도는 대부분 "Please cite authors"(저자 표기) 조건이므로 화면 하단에 USGS Astrogeology / NASA 출처를 표기합니다.

## 1. Solar System Scope (행성·태양·달·별)
- 주소: https://www.solarsystemscope.com/textures/download/ (파일명 그대로)
- 이용 조건: CC BY 4.0 (https://www.solarsystemscope.com/textures/ 에서 확인함: "목적을 가리지 않고, 상업 용도로도 쓰고 고쳐서 나눌 수 있다") → 출처 표기 필수
- **주의: 이 텍스처들이 모두 실제 사진·지도는 아니다.** 같은 페이지에 "NASA 고도·영상 자료에 기반하고 색은 메신저·바이킹·카시니의 실제 색 사진에 맞춰 조정했다. 아직 지도로 만들어지지 않은 부분은 주변 지형에 어울리는 가상의 지형으로 채웠다"고 적혀 있다 (지구가 가장 정확, 세레스·하우메아·마케마케·에리스는 "Fictional" 표기). 화면의 "실제 지도" 배지는 이 의미(실제 자료 기반)이며, 세레스는 이 사이트의 fictional 텍스처를 쓰지 않는다.
- 파일: 2k_sun, 2k_mercury, 2k_venus_surface, 2k_earth_daymap, 2k_earth_nightmap, 2k_earth_clouds, 2k_moon, 2k_mars, 2k_jupiter, 2k_saturn, 2k_saturn_ring_alpha(.png), 2k_uranus, 2k_neptune, 2k_stars_milky_way

참고
- 레아의 .tif(Rhea_Voyager_mosaic_global_833m.tif)는 보이저만으로 만든 부분 지도였고 마지막 한 줄이 모자라 쓰지 않았다(_trash/ 에 보관). 그래서 같은 페이지의 1024px 샘플을 사용한다. 더 선명한 레아 지도가 필요하면 후속 작업.
- 이오·유로파·가니메데·칼리스토는 경도가 서쪽 +(Positive West)이고 범위가 0~360(이오는 -180~180)이다. 화면에서 경도 기준이 어긋나면 텍스처 offset 으로 보정한다(M3).
- 명왕성·카론·트리톤 지도에는 관측되지 않은 남반구가 검게 비어 있다(실제 데이터가 없는 부분).
